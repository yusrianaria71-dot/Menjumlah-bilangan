Master Prompt Standar Industri

Persona • Tugas • Format • Konteks (Untuk Guru SD)

💡 Petunjuk untuk Guru: Gunakan prompt terstruktur di bawah ini saat meminta AI (seperti Gemini, Claude, atau ChatGPT) membuat modul, game, atau lembar interaktif baru. Anda bisa menyalin teks di bawah dengan tombol biru di kanan bawah!

### MASTER PROMPT: MEDIA PEMBELAJARAN INTERAKTIF MATEMATIKA FASE A (KELAS 1 SD) 1. PERSONA: Bertindaklah sebagai Senior Educational Game Developer & Spesialis Kurikulum Merdeka Fase A (Kelas 1 Sekolah Dasar) dengan keahlian khusus dalam pedagogical UI/UX design, visual storytelling interaktif, dan gamifikasi matematika ramah anak (early childhood numeracy). 2. TUGAS (TASK): Rancang dan buatkan satu aplikasi web media pembelajaran interaktif mandiri (Single-File HTML5, CSS Tailwind, dan Vanilla JavaScript) untuk materi "Penjumlahan Bilangan Cacah 1 sampai 10" yang: - Memandu anak dari pemahaman konkret (menghitung kumpulan gambar benda/buah) ke simbolik numerik (2 + 3 = 5). - Memiliki 2 mode: Mode Belajar Visual Interaktif dan Mode Kuis Berhitung Berhadiah Bintang (10 soal adaptif). - Menyediakan efek audio sintetis instan (Web Audio API) yang ramah anak tanpa bergantung pada file mp3 luar. - Memberikan efek visual selebrasi (confetti, bintang berkilau, goyangan gemas). - Dilengkapi tombol "Kembali ke Menu Awal" yang selalu dapat diakses di setiap halaman. - Terintegrasi fitur input nama dan pengiriman/penautan rekap skor otomatis ke Google Sheets / Google Form melalui Google Apps Script Webhook. 3. KONTEKS (CONTEXT): - Sasaran Pengguna: Siswa usia 6-7 tahun (Kelas 1 SD) yang sedang dalam masa transisi praoperasional ke operasional konkret menurut teori Piaget. - Kebutuhan Belajar: Anak membutuhkan umpan balik audio-visual instan. Anak belum lancar membaca teks panjang, sehingga tombol harus besar (touch-friendly), font bergaya ramah anak (Fredoka/Quicksand), dan warna cerah (pastel ceria). - Perangkat: Harus 100% responsif digunakan di smartphone Android/iPhone (orientasi tegak/portrait) maupun layar laptop/komputer proyektor kelas tanpa scroll horizontal. - Rekapitulasi Guru: Guru memerlukan bukti asesmen formatif yang dapat diekspor langsung ke spreadsheet agar penilaian tersimpan rapi. 4. FORMAT & SPESIFIKASI TEKNIS (FORMAT): - File Output: 1 Berkas HTML utuh (Single-File Mandiri) memuat seluruh HTML, Tailwind CSS melalui CDN, dan Script JS. - Audio: Diprogram langsung dengan synthesizer Web Audio API internal (nada instan chime C5-G5, nada salah boing, fanfare ceria) sehingga anti-error dan bebas kuota tambahan. - Visual: Emoji berkualitas tinggi sebagai objek hitung (🍎, 🍌, 🍓, 🦁, 🐰, 🚗, ⭐), CSS animations, dan Canvas Confetti. - Navigasi: Status State Machine yang bersih (Menu Utama -> Belajar -> Kuis -> Hasil Akhir), aman dari refresh yang merusak skor. - Integrasi Google Docs/Sheets: Formulir penampung URL Webhook Apps Script atau tautan Google Form Prefilled URL untuk sinkronisasi nilai otomatis.

Pengaturan Google Sheets Guru

Anda dapat menghubungkan game ini ke Google Spreadsheet sekolah agar setiap siswa selesai kuis, nilainya langsung masuk otomatis ke lembar rekap Anda!

*Biarkan kosong untuk mencoba mode demonstrasi simulasi otomatis.

Cara Pasang Cepat di Google Sheets:
  1. Buka Google Sheets baru, beri judul kolom: Timestamp, Nama Siswa, Skor, Detail.
  2. Klik menu Extensions > Apps Script.
  3. Tempel kode fungsi doPost(e) sederhana untuk menerima parameter JSON lalu deploy sebagai Web App (Who has access: Anyone).
  4. Salin tautan Web App tersebut dan tempel ke kolom di atas.
